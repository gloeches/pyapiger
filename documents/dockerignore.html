How to Create a .dockerignore File

The .dockerignore file prevents files from being copied into your Docker image. This is crucial for keeping your image small and for security. Create a file named .dockerignore in the same directory as your Dockerfile and add one of the following sets of rules.

Option 1: Ignore Everything Except Specific Files (Recommended)

This is the most robust method. It ignores all files and then creates exceptions for only the files you need. This ensures no unintended files (like system files, logs, or new files you add later) are accidentally included. 

# Ignore everything in the build context
**/*

# Allow specific files needed for the application
!api.py
!config.json
!requirements.txt

How it works: The **/* pattern tells Docker to ignore every file and directory. The ! prefix then negates the rule for the specified files, allowing them to be included.

Option 2: Ignore Specific Files and Folders

This approach involves explicitly listing the files and directories you wish to exclude. This can be useful in smaller projects but requires you to update the file every time you add a new directory that should be ignored. 

# Ignore the Python virtual environment
.venv

# Ignore VS Code settings
.vscode

# Ignore Docker related files that are not needed inside the image
Dockerfile

# Ignore any .dockerignore file itself
.dockerignore

How it works: Each line specifies a file or directory (relative to the build context) that Docker should ignore during the COPY or ADD operations. Since requirements.txt is no longer in this list, it will be included.
