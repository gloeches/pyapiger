PNPM Command and Workspace Guide

The pnpm-workspace.yaml File

The pnpm-workspace.yaml file is the configuration file used to define and manage a pnpm workspace. Its primary use is for monorepos, where you manage multiple projects or packages within a single, top-level repository.

This file allows you to specify which directories contain the projects that are part of the workspace. Beyond that, it can be used to set configuration options that apply to the entire workspace.

A key example of such a configuration is the minimumReleaseAge setting. When you set this option in pnpm-workspace.yaml, you enforce a rule across all projects in the workspace that prevents the installation of package versions that have been published more recently than the specified duration. This helps improve stability by avoiding brand-new, potentially buggy package releases. The value is a number that represents a duration in minutes. For example, to set a delay of 24 hours, you would use the value 1440.

Example pnpm-workspace.yaml:

# Defines the packages that are part of the workspace
packages:
  - 'packages/*'
  - 'apps/*'

# Workspace-wide settings
# The value is in minutes. 1440 minutes = 24 hours.
minimumReleaseAge: 1440

Common PNPM Commands

Here are some of the basic commands for managing packages in a pnpm project.

1. Installing a Package

To add a new package to your project, use the pnpm add command. This will install the package into your node_modules directory and add it as a dependency in your package.json file.

pnpm add <package-name>

For example, to install @types/node:

pnpm add @types/node

2. Listing an Installed Package

To check the currently installed version of a specific package, use the pnpm list command.

pnpm list <package-name>

For example, to see the installed version of @types/node:

pnpm list @types/node

3. Uninstalling a Package

To remove a package from your project, use the pnpm remove (or pnpm rm) command. This will uninstall the package and remove it from your package.json.

pnpm remove <package-name>

For example, to uninstall @types/node:

pnpm remove @types/node
